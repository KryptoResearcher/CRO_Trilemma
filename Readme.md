# CRO Trilemma - Reproducibility Repository

This repository contains all code necessary to reproduce the experimental results from the paper:

**"The Confidentiality, Reliability and Opposability (CRO) Trilemma in Post-Quantum Cryptographic Verification"**

## Quick Start

### Using Conda (Recommended)
```bash
# Clone repository
git clone https://github.com/KryptoResearcher/cro-trilemma.git
cd cro-trilemma

# Create environment and install dependencies
make install

# Run all experiments
make reproduce
